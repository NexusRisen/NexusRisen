## 👋 About Me

Hey! I'm the developer behind **Nexus Risen**. I build web apps, automation bots, and hosting setups for gaming communities—primarily focused on **Animal Crossing: New Horizons** and **Pokémon**.

My main project is **[GenACNH](https://genacnh.com)**, a full web platform that lets players order items, manage villagers, and customize islands in real time through web-to-console synchronization. Alongside that, I collaborate with the **[Sysbots Network](https://sysbots.net)** to help provide reliable, 24/7 hosting infrastructure for trade bots and community servers.

I love taking complex game systems and building fast, clean, user-friendly tools around them.
